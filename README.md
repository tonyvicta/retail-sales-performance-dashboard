# Retail Sales Performance Dashboard

> A portfolio project demonstrating job-ready skills for Customer Insights Analyst.

## Problem
Leadership needs a single view of sales performance to spot which categories and stores are over- or under-performing week to week.

## Context
Retail teams live or die by weekly sales performance — by store, category, and period.

## Tools & skills
- Excel / Spreadsheets
- Power BI

## Data
Use a public or synthetic dataset only. Never use confidential data from a current or previous employer. A public retail sales dataset (e.g. a Kaggle "retail sales" set) works well; a small synthetic set you generate is also fine.

**Source:** Kaggle public datasets

**Licence:** Check the dataset's licence permits portfolio/educational use before publishing.
